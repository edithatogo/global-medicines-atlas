# Specification: Comparison API and Atlas

## Outcome

Deliver v0.6 read-only CLI, API and accessible atlas for evidence-backed
regulatory-versus-funding comparisons.

## Requirements

- M-001 to M-005, M-035, M-073, S-005 to S-007.
- Expose provenance, valid time, observation time, uncertainty and coverage.
- Preserve jurisdiction-native terminology beside canonical mappings.
- Use bounded pagination, stable versioning and export-safe query contracts.

## Acceptance

- Contract, accessibility, security and end-to-end tests pass.
- Every visible conclusion drills down to source evidence.
- Unknown and uncovered states cannot render as negative status.

## Out of scope

- Write APIs, prescribing advice or unrestricted source redistribution.
