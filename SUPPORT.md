# Support

Use GitHub Discussions for non-sensitive questions when it is enabled. Use an
issue form for reproducible bugs, data-source proposals, and data incidents.
Security reports belong in private vulnerability reporting.

Start with the [task-oriented user guide](docs/user-guide.md) for installation,
execution, interpretation, reproduction, recovery, and reporting paths. The
[operations index](docs/operations/README.md) routes data incidents and local
recovery. Do not put credentials, restricted source material, personal
information, or exploitable medicine-data integrity details in Discussions or
a public issue; follow [SECURITY.md](SECURITY.md) instead.

The atlas is research infrastructure, not medical advice or clinical decision
support. Verify medicine status against the cited authority and effective date.
Support is best effort; the repository has one maintainer and no service SLA.
