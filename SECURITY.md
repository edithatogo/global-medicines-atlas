# Security policy

## Supported versions

Until version 1.0, security fixes are provided on the latest commit of `main`.
After 1.0, the current minor release is supported unless a release says otherwise.

## Reporting

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/edithatogo/global-medicines-atlas/security/advisories/new).
Do not disclose vulnerabilities, credentials, personal information, or exploitable
medicine-data integrity defects in a public issue.

The sole maintainer will acknowledge a report when practicable, assess severity,
and coordinate a fix and disclosure. No fixed response SLA is promised.

## Scope and safety

This project is not clinical decision support. Incorrect regulatory, funding,
price, or availability assertions may still cause harm; report integrity and
provenance failures privately when exploitation or coordinated disclosure is
relevant. Never submit patient-identifiable or confidential data.
