# Historical NZULM 2023 source archive

102 unchanged members recovered from the historical `nzulm_2023.zip`.
The source build is **27 November 2023**, with the **December 2023 Pharmac
edition**. This is a historical research archive, not current medicines
information, clinical advice, national coverage qualification or endorsement.

The exact source ZIP SHA-256 is
`757fb82b383f8d4d67ad7a1f7e26c25c2eaf05081a80290f4849f586fe58ffd9`.
The original mixed ZIP is **not distributed**. `manifest.json` binds every
published member to its original name, byte count and SHA-256. The six named
SNOMED mapping/guide members are excluded. No NZF content, full SNOMED/AMT
release, proprietary RxNorm vocabulary, private evidence or access URL is
included. The individual source-member bytes have not been altered.
