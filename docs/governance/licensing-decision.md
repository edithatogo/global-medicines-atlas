# Licensing decision

**Decision date:** 2026-08-01
**Decision authority:** Edith Atogo, repository copyright holder

The repository software is licensed under Apache-2.0. Eligible
maintainer-owned derived datasets are licensed under CC-BY-4.0 only when an
approved public artifact manifest explicitly places them within that scope.

Third-party medicine data, terminologies, documents, identifiers and mixed
derived outputs remain governed source by source. Neither licence overrides a
source licence, access condition, attribution duty, or redistribution
restriction.

This decision resolves the software-licence gate. It does not by itself approve
any dataset payload, establish live-source qualification, authorize disclosure
of restricted material, create a release, or complete an external publication.

## Evidence

- `LICENSE`: Apache License 2.0 text and copyright notice.
- `DATA_LICENSE.md`: bounded CC-BY-4.0 derived-data scope.
- `NOTICE`: attribution and third-party boundary.
- `pyproject.toml` and `CITATION.cff`: machine-readable software licence.
- `docs/data-sources/SOURCE_RIGHTS.md`: source-specific fail-closed policy.
