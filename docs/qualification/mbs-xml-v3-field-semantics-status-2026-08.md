# August 2026 MBS XML v3 semantics status

The Department's XML field guide describes native fields and declares the
`DD.MM.YYYY` date grammar. The guide is linked by the August 2026 release page,
but it was last updated on 4 March 2022 and does not provide a release-linked
field-semantic version history. The release page's statement that there were
no further XML changes compared with 28 May 2026 is not a complete field-level
change history.

Accordingly, the meanings and transformations catalogued in the
[candidate crosswalk](./mbs-xml-v3-field-semantics-2026-08.md) remain
provisional for the August 2026 release. `field_semantics_accepted` must remain
false until version-linked source evidence establishes those meanings for this
era. The current Department guide supports profiling its declared
`DD.MM.YYYY` grammar, and the exact hosted profile observed parseability, but
neither fact establishes release-specific field-semantic acceptance.

The original hosted candidate report is preserved unchanged as historical run
evidence. Its `field_semantics_accepted: true` interpretation is superseded by
this status record; its byte identity, source identity, field-presence counts,
and observed conversion counts remain historical observations. No source bytes
or values are included here.
