# Global Medicines Atlas source catalogue

This Hugging Face dataset contains catalogue metadata and schema definitions
for the Global Medicines Atlas. It is a discovery and interoperability
artefact, not a redistribution of third-party medicine source data.

## Contents

- `medicine_source_catalog.json`: source authorities, jurisdiction, dimensions,
  available fields, acquisition mode, and rights boundaries.
- `international-resource-v5.json`: canonical resource schema.

## Rights boundary

This catalogue does not grant rights to source data, terminology, product
information, or regulator/funder content. Each source remains subject to its
own licence, terms, access controls, attribution requirements, and publication
decision. Unknown or unresolved rights are withheld from public dataset
publication.

## Reproducibility

Canonical source and software repository:
<https://github.com/edithatogo/global-medicines-atlas>

The catalogue is generated and reviewed in the repository. See its source
