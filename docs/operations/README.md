## Action boundaries

Automated actions may validate fixtures, emit receipts, quarantine untrusted
payloads, deduplicate alerts, and rehearse local recovery. Operator actions may
triage failures, preserve evidence, stop promotion, and execute documented
local rollback. Credentials, external notification, source-rights decisions,
public release, retention/deletion policy, and production disaster-recovery
claims require maintainer authority.
