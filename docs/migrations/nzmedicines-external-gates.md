# nzmedicines External Gate Register

Local consolidation and restoration evidence does not authorize external
publication, redistribution, mirroring, or archival. Each gate below remains
pending until its required evidence is independently observable.

The source-family rights and compatibility disposition matrix is maintained in
[`nzmedicines-rights-disposition.md`](./nzmedicines-rights-disposition.md).
It records implemented local decisions and the fail-closed publication
boundary without converting unresolved rights questions into approvals.

| Gate | Status | Owner | Required evidence | Follow-up |
| --- | --- | --- | --- | --- |
| Publish the upstream compatibility notice | Pending | Maintainer | Action-time approval and published upstream URL | [#50](https://github.com/edithatogo/global-medicines-atlas/issues/50) |
| Change the upstream README or repository description | Pending | Maintainer | Approved diff and resulting upstream URL | [#50](https://github.com/edithatogo/global-medicines-atlas/issues/50) |
| Retain `nzmedicines` as a compatibility mirror | Pending | Maintainer | Scope decision, synchronization contract, and state receipt | [#50](https://github.com/edithatogo/global-medicines-atlas/issues/50) |
| Archive the upstream repository | Pending | Maintainer | Separate action-time approval and archive receipt | [#50](https://github.com/edithatogo/global-medicines-atlas/issues/50) |
| Redistribute the preserved Git bundle | Pending | Rights reviewer | Written rights decision and approved artifact manifest | [#51](https://github.com/edithatogo/global-medicines-atlas/issues/51) |
| Redistribute NZULM, NZF, SNOMED CT, RxNorm, PHARMAC, or related payloads | Pending | Rights reviewer | Source-by-source licence and provenance decision | [#51](https://github.com/edithatogo/global-medicines-atlas/issues/51) |
| Perform credentialed upstream GitHub mutations | Pending | Maintainer | Action-time approval and durable mutation receipt | [#50](https://github.com/edithatogo/global-medicines-atlas/issues/50) |
| Publish a public release or external attestation | Pending | Maintainer and rights reviewer | Passed release gates, approved manifest, public artifact, and attestation URL | [#32](https://github.com/edithatogo/global-medicines-atlas/issues/32) |

Closing the local migration track transfers these actions to the linked
follow-ups; it does not satisfy or waive them.
