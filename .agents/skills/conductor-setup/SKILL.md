# Conductor Setup

Load and follow the pinned upstream protocol at
`.agents/plugins/conductor/skills/conductor-setup/SKILL.md`.

This repository vendors that plugin as a Git submodule. Do not copy the
protocol into this wrapper. If the submodule is missing, run
`git submodule update --init --recursive`.
