# Global Medicines Atlas free-tier datahouse evidence

This experimental package contains only repository-authored synthetic records,
schemas, benchmark outputs, and non-sensitive aggregate receipts. It exists to
support a maintainer decision about optional datahouse technologies.

It contains no regulatory source payloads, personal data, credentials, or
rights-uncertain material. The package is not an authoritative Bronze store,
does not establish production durability or an SLA, and does not promote any
evaluated technology into the core Global Medicines Atlas architecture.

The package and its contents are licensed under Apache-2.0. `manifest.json`
binds every published file to its SHA-256 digest and publication classification.
